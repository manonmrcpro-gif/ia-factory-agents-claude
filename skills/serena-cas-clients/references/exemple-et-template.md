# Cas clients : exemple et template

## Exemple (extrait)

> **Hook** : « De 1 h par devis à 20 minutes : comment un studio de surface a fiabilisé son chiffrage. »
> **Avant** : 200 h/an de chiffrage manuel, mentions oubliées (risque juridique), zéro visibilité conversion. Avaient tenté un template Excel : abandonné en deux semaines.
> **Pont** : un agent de chiffrage branché sur leur book tarifaire, en 6 semaines, sans refondre leurs process.
> **Après** : chiffrage divisé par 3, zéro mention oubliée, +10 % de conversion. **En 6 semaines.**
> **Citation** : « Je ne passe plus mes dimanches sur Excel. Et mes clients reçoivent leur devis dans l'heure. » : Sophie, dirigeante.

## Template

```
HOOK (le résultat le plus fort, pas le nom du client) : « … »
BANDEAU (site) : secteur · taille · stade · outils

AVANT : [situation + douleur précise + ce que ça coûtait + tentatives ratées]
DÉCLENCHEUR : [pourquoi il a bougé maintenant]
PONT (ce qu'on a fait) : [actions clés, pas le détail technique]
APRÈS : [résultats chiffrés : temps / argent / conversion] · DÉLAI : « en __ semaines »

CITATION DE CLÔTURE : « … » : [prénom, rôle]
CTA : « … »
ACCORD CLIENT : [✅ obtenu / ❌ à demander]
```
